# ZB202 占用、CO₂ 与控制研究原型

第一阶段完成情况及真实 IoT 数据的使用边界见 [Word 执行简报](ZB202_execution_report.docx)。

## 范围

这是一个用于验证软件链路的仿真实验，尚未控制现场 VAV。当前已知房间平面 5.9 × 7.9 m，净高 6.1 m，按单区完全混合假设体积为 284.321 m³。ZB202 有独立 VAV，但点位、可写权限、总送风与室外新风的关系还未确认。

## 方法

- 0–10 人的占用轨迹由种子生成，包含分组到达和持续停留；它不代表实测人数。
- 时变马尔可夫转移矩阵通过 120 个**另外生成**的模拟日估计，采用时间邻域平滑和伪计数。它借鉴论文的非齐次马尔可夫链思路，**未实现论文的自适应 B 样条拟合**。每一步用当前模拟人数初始化分布，前推 24 步的期望人数和占用概率。
- CO₂ 使用精确离散化的单区质量守恒方程：`C_next = C_eq + (C_now - C_eq) exp(-Q Δt / V)`，其中 `C_eq = C_out + 10^6 G n / Q`。`Q` 是有效室外空气流量，不是总送风量；`G = 0.018 m³/(h·人)` 来自参考论文。
- 比较固定 300 m³/h、按当前人数响应、以及基于未来概率占用的控制。预测控制每 5 分钟用束搜索近似优化接下来 2 小时，只取首个建议风量，再滚动重算。这是受论文启发的**简化原型**，并非论文的 Gurobi 二次规划或温度/能耗联合 MPC。
- 目标 800 ppm，室外浓度 420 ppm，风量候选 100、200、300、450、600 m³/h 都是仿真假设；这些值不是现场安全或运行设定值。

## 结果与解释

运行 `npm run results` 会重建 `simulation-summary.json` 和 `representative-day.csv`。汇总使用 20 个评价日，并记录各日结果。三种策略在每个评价日使用同一条人数轨迹。指标包括占用时超目标分钟数、CO₂ 峰值、占用时平均 CO₂、累计室外空气量和风量切换次数。

累计室外空气量是通风量代理指标，不是实际电耗、制冷能耗或碳排放。由于人数和风量都是模拟的，结果不能证明 ZB202 的实际人数预测准确率、现场 CO₂ 预测精度或节能率。页面通过本地桥接取得的真实 CO₂ 读数只能手动选为初始状态，不参与生成模拟人数，也不被当作验证标签。

当前 20 个模拟日的平均结果为：固定通风占用时超目标 22.3 分钟、累计室外空气量 7200 m³；当前人数响应为 0 分钟、3989 m³；预测控制为 41.5 分钟、2890.5 m³。预测控制在这组暂定权重下减少了风量代理值，但牺牲了部分 IAQ 表现。这一结果表明需要进一步调整权重和约束，不能报告为“预测控制全面优于基线”。

## 现场接入仍需

1. ZB202 独立 VAV 的 BMS 点位表：风量设定值、实际值、风阀反馈、上下限、运行状态和故障状态。
2. 总送风量与有效室外空气量之间的关系，以及 AHU 新风比例或测点。
3. 经批准的只读趋势数据和小幅人工阶跃实验，用于辨识房间响应。
4. 写入权限、实验时段、最小通风要求、人工接管和故障回退。取得并验证这些条件后，再考虑从影子模式进入现场控制。
